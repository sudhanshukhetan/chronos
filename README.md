# CHRONOS: Genesis of the Living Sphere

An immersive, scroll-driven WebGL / Three.js cinematic journey traveling from the cosmic void to the birth of the living Earth.

## ✨ Features

- **Cinematic Countdown & Big Bang Revelation**:
  - High-speed synthesized numeric countdown (100 to 0) with dynamic per-tick Web Audio clicks.
  - Particle shockwave burst, camera shake, and explosive sonic bloom on ignition.
- **Synthesized Web Audio Engine**:
  - Procedural soundscape (no external audio files required).
  - Deep meditative resonant drones, pink-noise ocean waves, procedural rain sweeps, plasma roar, and tectonic collision impacts.
- **Photorealistic WebGL Graphics**:
  - 35,000+ depth-sorted particles for the Milky Way with logarithmic spiral arms and interstellar dust lanes.
  - Solar Corona and dynamic multi-frequency noise chromosphere shader.
  - Molten Hadean Proto-Earth with glowing magma fractures and volcanic atmosphere.
  - Theia giant planetary collision sequence with volumetric orbital debris ring formation and camera shake.
  - NASA-grade photorealistic Earth with dual-layer cloud sphere, continental elevation gradients, ocean specular glint, Rayleigh atmospheric scattering, and night-side city lights.
- **Scrollytelling & Interactive Tooltips**:
  - 9 scientific chapters powered by GSAP ScrollTrigger.
  - Interactive tooltip cards explaining astrophysical and planetary evolution concepts.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser that supports WebGL and Web Audio.

```bash
# Optional: Serve locally using Python or any static web server
python3 -m http.server 8000
```
Open `http://localhost:8000` in your browser.
